# 紫微斗數

固定三段式輸出：**整體運程 → 十二宮立極四化分析 → 飛星宮位轉換**。

| 檔案 | 用途 |
|---|---|
| [scripts/ziwei.py](scripts/ziwei.py) | 排盤、四層四化、宮干飛化、化入統計、祿忌循環、宮位轉換、流月。所有計算都用它，不要手算 |
| [stars.md](stars.md) | 星曜與四化的象義表。論象時用它，不要臨場自創意思 |
| [reference.md](reference.md) | 安星規則與查表資料，用來理解和核對程式的輸出 |
| `profiles/` | 命主檔案：`<名稱>.json` 是排盤資料，`<名稱>.md` 是現實背景和驗盤記錄 |

## 第零步：讀盤與定設定（每次都做，並在回覆開頭簡述）

1. **找命主檔案**。`profiles/` 裡有這位命主的檔案就直接用。沒有的話，照 `profiles/_template.json` 和 `profiles/_template.md` 建立：
   - 從截圖讀出性別、農曆出生年月日、時辰，填入 JSON。`birth_year` 是農曆年（干支年）。
   - 看不到農曆生日時，`lunar_day` 填 `null`，把盤面上紫微所在的地支填入 `ziwei`。
   - 程式不計算的星（紅鸞、天喜、天姚、天刑、咸池等雜曜）照盤面填入 `extra_stars`。
   - 命主檔案含個人資料，已被 `.gitignore` 排除。除非使用者明確要求，不要提交到 git。
2. **跑程式排盤**，在 skill 資料夾內執行：

   ```bash
   python3 scripts/ziwei.py chart  profiles/<名稱>.json              # 本命盤
   python3 scripts/ziwei.py decade profiles/<名稱>.json <虛歲>        # 該虛歲所在的大限
   python3 scripts/ziwei.py year   profiles/<名稱>.json <西元年>      # 流年，含流月
   ```

   加上 `--taichi <宮>`（命、兄、夫、子、財、疾、遷、友、官、田、福、父）會另以該宮立太極，列出十二個轉換身分的星曜和四化。
3. **核對截圖**：把 `chart` 的輸出和截圖逐宮比對命宮、身宮、五行局、宮干、主星、輔星和煞星。
   - 有不同就先檢查月份、生日和時辰有沒有讀錯。
   - 確認是流派差異（例如庚干的天魁、天鉞）時，把盤面的位置寫入 JSON 的 `overrides`，並在回覆中說明。
   - 程式顯示「注意」時，要在回覆開頭交代。
4. **庚干化科分歧**：太陰或天府。看盤上的標示，寫入 JSON 的 `geng_ke`（文墨天機用太陰），並在開頭註明。
5. **讀命主的現實背景**（`profiles/<名稱>.md`）。論象要配合婚姻狀況、職業等背景；背景是「待補」時，照實說不知道，並列出各種情況下的解讀，不要推測。
6. **第一次看這張盤時先定盤**：請使用者提供 3–5 件已發生的大事和年份（置業、結婚、轉職、重病、親人離世等），用 `year` 逐年核對。大部分對不上時，先懷疑時辰，試前後一個時辰再比較。結果記入命主檔案。
7. 分析層次的定義（大限、流年、小限、斗君）在 reference.md。流月四化預設用月干，使用其他方法時要說明。

## 第一段：整體運程

- **第一句先給結論**：一句話評級（例如「中上、外順內亂」），再列 3–6 點主軸。
- 主軸從以下來源找：
  - 流年命宮與三方四正（命、財、官、遷）的星曜、四化與煞星。
  - 四化匯聚最重的宮，例如同一宮有多層祿忌或雙忌。
  - 化忌落點與化忌所沖的宮。
  - 流年命宮的宮干飛化。
  - 格局，例如祿馬交馳、鈴貪格、日月並明、羊陀夾、刑忌同宮、機月同梁、殺破狼。
- 分項（事業、財運、感情、健康、人際、家宅或置業、上司或文書）用短段落或表格呈現，每一點都附上判斷依據。

## 第二段：十二宮立極四化分析

對每一宮（依使用者要的層次，通常是流年十二宮或大限十二宮）都寫以下內容：

| 項目 | 內容 |
|---|---|
| 疊宮 | 這一宮同時是本命、大限、流年、小限的哪一宮，地支與宮干 |
| 星曜 | 主星與亮度、重要輔星與煞星（含流年羊陀、魁鉞、昌曲、天馬） |
| **化入** | 坐在本宮的生年、大限、流年、小限四化，以及其他宮宮干飛入本宮的祿權科忌（註明來自哪一宮） |
| **化出** | 本宮宮干的祿權科忌各飛入哪一宮（寫成「X 祿入 Y」） |
| **自化** | 本宮宮干化本宮的星，稱離心自化（祿、權、科、忌外散）。是否處理向心自化要先說明 |
| 匯合判斷 | 同星祿忌交戰、科忌同星、雙忌、三化同星、忌沖對宮等，翻譯成實際表象 |
| 課題或建議 | 一句話 |

規則：

- 只以宮干飛化，不憑感覺加四化。化入、化出、自化、統計和循環一律引用 `scripts/ziwei.py` 的輸出，程式沒有列出的飛化不可以寫。
- 每條四化的意思從 [stars.md](stars.md) 取：先看星性，再看四化，然後看宮位。同一個象至少列出兩種可能的表現，並說明哪一種較可能和原因。
- 化忌一定要追兩件事：落宮的意義，以及它沖的對宮（程式的「化出」表已列出）。
- 用程式的「化入」統計找出全盤的「匯聚點」，並特別點出。
- 用程式的「化祿循環」和「化忌循環」。祿循環代表良性系統，忌循環代表反覆糾纏的課題。

## 第三段：飛星宮位轉換

每個宮除了本身的意義，也是其他宮的某一宮。換算方法（宮序逆排：命 0、兄 1、夫 2、子 3、財 4、疾 5、遷 6、友 7、官 8、田 9、福 10、父 11）：

> B 宮相對於 A 宮的身分 ＝ (序號 B − 序號 A) mod 12

例如疾厄宮（5）相對於官祿宮（8）是 (5 − 8) mod 12 = 9，也就是田宅宮，所以疾厄宮是「官祿宮的田宅宮」。完整矩陣在 reference.md。

引用任何轉換身分前，先用程式查，不要憑記憶：

```bash
python3 scripts/ziwei.py convert 官 疾     # 疾厄宮是官祿宮的哪一宮
python3 scripts/ziwei.py convert 官        # 十二宮相對於官祿宮的身分
python3 scripts/ziwei.py year profiles/<名稱>.json 2028 --taichi 疾   # 以流年疾厄宮立太極，連同星曜和四化
```

做法：

1. 對每個有四化落入或化出的宮，列出它對重點宮（命、財、官、田、夫）的轉換身分。
2. 用轉換後的意義解釋四化。例如：
   - 疾厄宮是官祿宮的田宅宮：疾厄宮有化祿，代表工作的根基與環境穩定；有化忌，代表工作的根基受損，例如公司內部問題、職場環境不佳，或身體拖垮事業。
   - 兄弟宮是財帛宮的田宅宮（財庫）：兄弟宮的祿忌就是財庫的進出。
   - 子女宮是田宅宮的遷移宮：子女宮的四化影響搬遷或外地物業。
   - 父母宮是官祿宮的子女宮與疾厄宮的遷移宮：可看上司或文書如何牽動事業的分支項目，以及身體狀況。
   - 交友宮是財帛宮的子女宮與官祿宮的父母宮：可看投資外放的風險，以及與上級、大客戶的關係。
   - 命宮是官祿宮的財帛宮：你本人就是事業的收入來源。
   - 夫妻宮是官祿宮的遷移宮：配偶或感情影響事業的外在表現。
3. 宮干飛化也照轉換思路解讀。例如「疾厄宮宮干化忌入官祿宮」，等於「官祿宮的田宅宮化忌回到官祿宮本身」，代表根基問題回頭衝擊事業。
4. 至少挑出 3–5 條影響最大的轉換關係詳細說明，其他的用表格帶過。

## 專題問題的處理

- **應期（例如何年置業、結婚）**：
  - 逐年看本命、大限、流年三個目標宮（例如田宅宮）的化入、化出。
  - 重點看命宮或財帛宮飛化入目標宮，以及目標宮飛忌入本命目標宮（收藏入庫）。
  - 尋找與已驗證年份（例如過去的置業年）結構相同的年份。
  - 用表格做評級排序。
- **流月**：用斗君定正月命宮，順排；列出每月的流月命宮（流年與本命宮位）、四化重點和星級評分，再標出最好和最差的月份。
- **大限人生課題**：大限十二宮立極加上祿循環和忌循環，並比較本命格局與大限三方格局的差異（例如殺破狼轉為機月同梁）。
- **外貌**：合看本命夫妻宮與大限夫妻宮的星性，只描述類型，不給具體身高數字。
- **戰爭、天災等集體事件**：說明個人命盤無法判斷，只能看遷移、動盪等個人層面的信號，並給實際的準備建議。

## 驗盤記錄（每次分析後更新命主檔案）

- 使用者確認發生過的事，連同對應的盤象，記入 `profiles/<名稱>.md` 的「已驗證事件」。
- 每次提出可以用現實核對的推論（例如某年置業、某月人事變動），在「待驗證的推論」加一列，寫明可觀察的現實指標。
- 使用者回報結果後，把該列移到「已驗證事件」，並註明吻合或不吻合。不吻合的也要記，之後遇到相同的盤象要調整解讀。
- 使用者提到新的現實背景（婚姻、工作、物業）時，更新「現實背景」。
- 做應期判斷時，先看「已驗證事件」，找和已驗證年份結構相同的年份。

## 輸出風格

- 使用者用繁體中文時，用繁體中文回覆。
- 開頭先給結論；表格只放可列舉的事實，解釋寫在表格外的段落中。
- 寫「X 宮的化祿入 Y 宮」這類完整句子，不使用箭頭鏈或自創代號。
- 每個判斷都附上星曜、四化或宮位的依據。
- 結尾提醒命盤只看傾向，實際決策要配合現實條件；可再提議下一步分析（流月、流日、某宮深入）。
